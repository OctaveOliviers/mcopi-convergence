\begin{lemma}
\label{thm: all qpol in Pinf are equivalent}
    Given an initial condition $q$, let $(\pol_k)$ be the sequence of policies generated by system \eqref{eq: update unbiased over policies}.
Under \autoref{asp: unbiased over policies},
\begin{align}
    \forall \ q \in \qset, \
    \exists \ K > 0, \
    \exists ! \ \pol \in \polset
    \ : \
    \pol_k = \pol, \ \forall k > K .
\end{align}
% In other words, there is only one policy that system \eqref{eq: update unbiased over policies} encounters infinitely often.
\end{lemma}
\begin{proof}
% Note that for any set of policies, the number of transitions between these policies is always larger than the maximal number of visits to any of the individual policies.

\newcommand{\Pinf}{\polset_\infty(q)}

Let the set $\Pinf \subseteq \polset$ contain all the policies that system \eqref{eq: update unbiased over policies} encounters infinitely often when initialised in $q$, and suppose that $\Pinf$ contains more than one policy.
Since system \eqref{eq: update unbiased over policies} encounters each policy in $\Pinf$ infinitely often,
% then an infinite number of transitions occur between the policies in that set.
it must exit the region of each policy in $\Pinf$ infinitely often.
As a result, for every policy $\pol \in \Pinf$
there exists at least one other policy $\pol_+ \in \Pinf$ that directly succeeds $\pol$ an infinite number of times
and, by \autoref{thm: policy improvement if visit infinitely often}, is strictly better.
% Similarly, there exists at least one other policy $\pol_- \in \Pinf$ that directly precedes $\pol$ an infinite number of times
% and, by \autoref{thm: policy improvement if visit infinitely often}, is strictly worse.
However, this conclusion is incompatible with the finiteness of the set $\Pinf$. 
% or the transitivity of the partial order in the policy set $\polset$.
Therefore, the set $\Pinf$ contains a single policy.
\end{proof}

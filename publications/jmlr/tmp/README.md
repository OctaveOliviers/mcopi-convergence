# JMLR proof workspace

Store reference transcriptions, exploratory proofs and supporting material here
while developing the JMLR proof. This directory is separate from the active
manuscript and is not included by `jmlr.tex` or the main paper build.

Despite its name, `tmp/` is a versionable working area. Keep useful sources,
provenance and validation records; ignore disposable build files. Give each
experiment its own folder and distinguish faithful source transcriptions from
proposed changes. Move material into the manuscript only after the appropriate
mathematical and exposition reviews.

[simplified-proof-reference/](simplified-proof-reference/README.md) contains the
reconstructed LaTeX for Sections 1–3 of the supplied candidate proof, its compiled
PDF and the transcription validation record.

[proof-replacement/](proof-replacement/README.md) retains the revised proof
increments and the integration candidate. See [the current review status](../STATUS.md)
for the active manuscript and completed checks.

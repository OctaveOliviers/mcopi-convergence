\begin{abstract}
We prove almost-sure convergence of initial-visit Monte Carlo optimistic policy iteration
when initial actions are uniform within each state and every state accumulates infinite
learning weight. State sampling may be adaptive and may vanish for arbitrarily long
intervals. The result covers finite discounted and proper undiscounted episodic Markov
decision processes, unbiased returns with uniformly bounded conditional variance, fixed-priority or fully inertial ties, and square-summable, eventually nonincreasing deterministic
steps, without an additional comparability condition. The estimates converge to the optimal
action values, the policy-evaluation target changes only finitely often, and all sufficiently
late policies are optimal. Three sampled counterexamples show that convergence need not
survive replacing Monte Carlo targets by forward TD($0.99$), updating every first-visited
pair, or biasing initial actions toward the greedy action. Each changes only one of these
algorithmic choices and retains a positive sampling floor. The examples establish sharpness
in these three directions, without asserting absolute maximality.
\end{abstract}
